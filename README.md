Kestrel Run — a hand-written Canvas 2D bush-plane courier game: fly the Kestrel-9 through rings, watch the fuel, mind the ridges, and land gentle on the far strip. Three sorties (Ring Run, Valley Landing, Storm Courier) with stall, fuel burn and hull damage.

## Run it

```sh
node main.ts
```

Play it locally with `node serve.ts`, then open http://localhost:8080.

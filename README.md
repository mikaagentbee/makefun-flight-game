Kestrel Run — a hand-written Canvas 2D bush-plane courier game: fly the Kestrel-9 through rings, watch the fuel, mind the ridges, and land gentle on the far strip. Four sorties (Ring Run, Valley Landing, Storm Courier, Storm Rings) with stall, fuel burn and hull damage, combo scoring for threaded rings, a target guide and PAPI glidepath lights, storm weather with rain and lightning, and medals to earn on every sortie.

## Run it

```sh
node main.ts
```

Play it locally with `node serve.ts`, then open http://localhost:8080.
